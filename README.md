# BiBi Workspace

BiBi Workspace is a course management, note-taking, planning, timetable scheduling, file tracking, and cloud synchronization platform in one polished web application.

## Live Demo

[View Live Demo](https://bibiworkspace.vercel.app/)

## Description

BiBi Workspace is a web application designed to help students manage their academics and study workflow. It includes:

- Course and syllabus tracking
- Linked study notes and note editor
- Planner and quick tasks
- Timetable management
- Course files management
- Cloud-synced workspace data

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
